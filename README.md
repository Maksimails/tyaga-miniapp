# Тяга — Telegram Mini App

Это первая версия **отдельного** Telegram-мини-аппа Тяги (не часть Силы Слова) — тот же кликабельный прототип, что был в демо-артефакте, но:

- без фейковой рамки телефона — растягивается на весь реальный экран Telegram;
- подключён `telegram-web-app.js` (официальный Telegram WebApp SDK);
- аппаратная кнопка «Назад» в Telegram теперь реально работает и синхронизирована с навигацией внутри аппа;
- лёгкая haptic-вибрация на нажатия кнопок/карточек (если поддерживается клиентом);
- подтверждение закрытия аппа, если пользователь на середине сценария (заполняет обещание/квиз), чтобы случайно не потерять прогресс;
- поправлена высота под `viewportStableHeight` Telegram (учитывает системную клавиатуру, safe-area на iPhone).

Логика экранов, состояние, весь текст — без изменений относительно прототипа: это шаг «упаковать в реальный мини-апп», а не переделка сценариев.

## Что нужно, чтобы это стало настоящим ботом в Telegram

### 1. Захостить `index.html`

Telegram Mini App обязательно требует **HTTPS**-адрес. Файл полностью самодостаточный (весь CSS/JS внутри одного файла) — можно залить как есть на любой статический хостинг:

- **Vercel** / **Netlify** — самый быстрый способ: перетащить папку в интерфейс или `vercel deploy` / `netlify deploy` в этой папке.
- **GitHub Pages** — закоммитить `index.html` в репозиторий, включить Pages.
- Любой свой сервер, отдающий статику по HTTPS.

Получите URL вида `https://tyaga-app.vercel.app/`.

### 2. Создать бота и подключить Mini App через BotFather

1. В Telegram открыть **@BotFather**.
2. `/newbot` — если бота ещё нет, задать имя и юзернейм (например, `TyagaAppBot`). Если бот для Тяги уже существует — пропустить этот шаг.
3. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → **Configure Menu Button** → указать хостнутый URL из шага 1. Это добавит кнопку меню, открывающую мини-апп прямо в чате с ботом.
4. Опционально: `/newapp` в BotFather — регистрирует полноценный Mini App с собственной карточкой (иконка, описание, короткое имя вида `t.me/TyagaAppBot/app`), который можно расшаривать отдельной ссылкой, не только через меню бота.

### 3. Проверить

Открыть бота в Telegram (на телефоне — там нативный опыт нагляднее, чем в Telegram Desktop), нажать кнопку меню — мини-апп должен открыться на весь экран, кнопка «Назад» в шапке Telegram должна появляться/скрываться в такт навигации внутри аппа.

### 4. Дальше (не в этом файле, а по мере готовности)

- Настоящая авторизация через `Telegram.WebApp.initData` (сейчас не проверяется — для теста на своих людях не критично, но для продакшена нужна валидация на бэкенде).
- Бэкенд: сохранение обещаний/прогресса/квиза не в `localStorage` браузера, а в реальной базе (иначе прогресс пользователя живёт только в одном устройстве и стирается при переустановке).
- Приём платежей — либо через `Telegram.WebApp.openInvoice` (нативные Telegram-платежи), либо через встроенную сейчас логику ЮKassa/Apple Pay как отдельный шаг оплаты внутри веб-вью.
- Домен/бренд отдельно от Силы Слова (см. п.14 `tyaga-spec-v2.md`) — на этом этапе технически это просто вопрос того, под каким ботом и на каком URL всё это висит.
